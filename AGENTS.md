# Publishing Vote Room

- Keep the public GitHub repository `ripper234/vote-room` in sync with every published Sites source change. Do not consider a release complete until both contain the change.
- The Sites project ID is in `.openai/hosting.json`. Preserve its D1 binding and public access. Do not create a replacement Site for routine edits.
- Never commit `.env` files, recovery keys, voter records, or local database state. The public repository contains code and editorial content only.
- Keep the experience open to visitors without a login and keep party information source-grounded and neutral.
